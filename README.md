# فاحص برو X1 — تطبيق الفحص متعدد المنصات

تطبيق Flutter (أندرويد + iOS) لجهاز فحص السيارات **فاحص برو X1**، يدعم فحص الأنظمة والأوسيلوسكوب رباعي القنوات والبرمجة والتكويد عبر الإنترنت.

## الميزات

| الميزة | الوصف |
| --- | --- |
| فحص الأنظمة | قراءة ومسح أكواد الأخطاء (DTC) ودعم أكثر من 200 موديل |
| البرمجة والتكويد | تحديث وحدات التحكم وتفعيل المزايا عبر الإنترنت |
| الأوسيلوسكوب | 4 قنوات ملونة مع قياس مباشر للجهد والتردد |
| البطارية | مؤشر شحن (18600 mAh) مباشر من الجهاز |
| البروتوكولات | CAN FD + DoIP مع لوحة توضيحية في الإعدادات |
| الواجهة | واجهة أندرويد بالعربية مع دعم RTL و Material 3 |

## التشغيل

المشروع بُني بدون مجلدات المنصات (لا يتطلب تثبيت Flutter في مرحلة البناء). لتوليدها وتشغيل التطبيق:

```bash
# 1) ثبّت Flutter SDK من https://flutter.dev
# 2) من داخل مجلد المشروع
cd ~/Desktop/car-scanner-app
flutter create . --platforms=android,ios
flutter pub get
flutter run
```

## البنية

```
lib/
├── main.dart                 # نقطة الدخول + الإعدادات الإقليمية (ar)
├── theme/                    # Material 3 + الألوان (وضع داكن)
├── models/                   # Vehicle, DtcCode, ScopeChannel, DeviceInfo, CodingModule
├── services/                 # واجهات الخدمة + تنفيذات محاكاة (Mock)
├── state/                    # AppState عبر Provider
├── screens/                  # الشاشات الخمس + شاشات الاتصال واختيار المركبة
└── widgets/                  # مكونات مشتركة (بطارية، حالة اتصال...)
```

## ملاحظات تقنية

- جميع الخدمات (`DeviceService`, `ScanService`, `OscilloscopeService`, `CodingService`) واجهات مجردة؛ التنفيذ الحالي **محاكاة (Mock)** ببيانات تجريبية.
- للاتصال الفعلي بالجهاز، استبدل التنفيذات المبدئية بحزم الاتصال (مثل `flutter_blue_plus` للبلوتوث، أو `serial_port_win32` / WiFi Socket) دون تغيير الواجهات.
- الكود يعتمد على Flutter 3.29+ (يستخدم `CardThemeData`, `withValues`).
